- 悦起文化 / JoyKey 既有 IP 的个人 AIGC 视觉延展练习：跃出纸面、暖灯陪伴、钥匙孔奇境与整幅海报毛绒化，附参考原海报、创作思路、本人职责与应用设想。

- 《冬烬之地》完整短片（网页 MP4，保留声音）与作品介绍。

- 手机布局、键盘导航、减少动态效果设置与图片/视频错误提示。
- 桌面首页鼠标轻视差，手机端一次入场；入口按钮薄荷绿滑入和回弹反馈。
- 作品按当前网格阅读顺序依次入场，图片预览带打开、切换和关闭过渡。

动效使用原生 CSS 与浏览器动画 API，无额外依赖。视差仅在首页可见且使用鼠标时启用，移动停止后动画循环也会停止。系统启用「减少动态效果」时，视差与入场/预览动画会自动简化。

音乐由访客点击开启，首次打开页面不下载音频。歌曲与影片播放互相暂停，避免声音重叠；一首播放结束后，会继续当前分类中的下一首，到分类末尾停止。首页背景音乐尚未指定。

## 本地预览

在本目录运行：

```sh
python3 -m http.server 8080
```

浏览器打开 http://localhost:8080 。网站是纯静态 HTML/CSS/JavaScript，无需安装前端依赖或进行打包，也可以直接双击 index.html。

## 更新数字人视频

数字人视频位于「色彩与日常」区域的「把声音，变成画面。」标语之后。数字人区域已加入用户提供的 `JOYO_AC20S_AC40S_Bilingual.mp4`，网页文件为 `assets/video/digital-cassie.mp4`。仅调整 MP4 索引位置，保留原 H.264 / AAC 编码、完整画幅、原声和画面中的双语字幕。封面提取自影片，点击封面后才加载视频；播放器会暂停其他正在播放的音频或影片。

1. 把最终视频保存为 `assets/video/digital-cassie.mp4`。
2. 修改 `site-config.js`：

```js
window.PORTFOLIO_CONFIG = {
  digitalHumanVideo: './assets/video/digital-cassie.mp4',
  digitalHumanPoster: ''
};
```

3. 如有视频封面，添加至 `assets/images/`，在 `digitalHumanPoster` 填入相对路径。
4. 推送到 GitHub，GitHub Pages 会更新网站。填写视频路径后，预留界面自动替换成带播放控件的视频。
